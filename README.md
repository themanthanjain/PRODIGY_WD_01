# PRODIGY_WD_01
A responsive landing page featuring a fixed, interactive navigation menu that dynamically changes styling based on scroll position and user hover states. Built with HTML5, CSS3, and vanilla JavaScript. Completed as Task 01 for the virtual Full-Stack Web Development internship at Prodigy InfoTech.

# Responsive Landing Page - Task 01

This repository contains the source code for a responsive landing page built with HTML, CSS, and JavaScript. 

## Features
* **Fixed Navigation Bar:** Stays anchored to the top of the viewport across all sections.
* **Scroll Interactivity:** The navigation background and drop-shadow dynamically transition when the user scrolls past the hero section using JavaScript event listeners.
* **Hover States:** Smooth CSS transitions applied to navigation links for better user experience.
* **Fully Responsive:** Layout adapts cleanly across different screen sizes.

## Technologies Used
* HTML5
* CSS3 (Flexbox, Transitions)
* Vanilla JavaScript (DOM Manipulation, Event Listeners)
